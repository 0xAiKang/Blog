使用 Simulator 开发 React Native 应用时，在 Debug 模式下，虽然能 Console 调试，但是不能像 Web 开发一样，在控制台的 Network 看到网络请求，因此开发调试问题时，很不方便。

Reactotron 是一个用于 React JS 和 React Native App 的网络请求调试工具，就可以很好的实现该功能。
